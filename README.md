# Users Manager

אפליקציית Android לניהול משתמשי מערכת במכשירים שבהם Root זמין.

## יכולות
- הצגת משתמשי Android הקיימים.
- יצירת משתמש מערכת חדש באמצעות `pm create-user`.
- מעבר משתמש באמצעות `am switch-user`.
- זיהוי מגבלת המשתמשים של המכשיר.
- אין מחיקה של משתמשים.

## דרישות
- Android 8.0 ומעלה (minSdk 26).
- Root פעיל ומאושר למעטפת `su`.
- המכשיר עצמו חייב לתמוך ב-Multi-user.

הערה: Root לא עובר אוטומטית למשתמשים משניים. פעולות ניהול מתבצעות דרך הרשאת Root של התהליך.

## Build
GitHub Actions בונה APK מסוג Debug ומעלה אותו כ-artifact.
